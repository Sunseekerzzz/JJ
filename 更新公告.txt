无损视频剪辑工具 v13.4 更新公告 (2026-09-27)
==============================================

【本次更新】修正「播放选区」的起点

■ 现在播的就是你框选的那一段

1. 以前的行为(不对)
   · 只要你在时间轴上点过一下(移动红色播放头做单帧预览),再点「▶ 播放选区」,
     播放就会**从那个插针位置**开始,而不是你框选范围的起点
   · 原因:旧代码把"播放头"和"选区起点"取较大者当作播放起点,与按钮名字「播放选区」不符

2. 现在的行为
   · 「▶ 播放选区」= 播放**框选的那一段**,永远从「选区起点」播到「选区终点」
   · 插针在选区内 / 选区之前 / 选区之后,都一样从选区起点开始
   · 播放过程不会再挪动插针位置

3. 顺带修正
   · 起点 = 终点(选区被拖没了)时提示:"当前选区为空…请在时间轴上拖出端点、框选一段区间后重试"
   · 运行日志改为「播放选区: 0:00:01.000 → 0:00:04.000 (选区范围, 1x)」

4. 保持不变
   · 「⏮ 起点 = 播放头」「终点 = 播放头 ⏭」按钮照旧可用
   · 拖动红色播放头仍然实时预览单帧(插针只代表"我要看这一帧",不参与播放起点)

【安装位置】
本次已自动部署到: C:\RJ\LosslessVideoEditor\
桌面快捷方式: 无损视频剪辑

无损视频剪辑工具 v13.3 更新公告 (2026-09-27)
==============================================

【本次更新】播放立刻有反馈 + 取消时间轴双击

■ 「播放选区」不再"点了没反应"

1. 点击「▶ 播放选区」后,界面**立刻**给出反馈
   · 底部弹出进度条,显示「正在启动播放器…」
   · 右下角状态栏同步提示;超过 1.5 秒会显示已等待多久

2. 播放器窗口一出现,进度条自动收起,转为「正在播放预览…」

3. 为什么以前像"没反应"
   · ffplay 是**独立程序**,从点击到窗口出现要经历:启动进程 → 定位播放点(seek) → 解码首帧
   · 小素材约 0.6 秒;4K / 高码率录屏可达数秒 —— 这段时间界面完全没有任何变化
   · 现在这段时间有明确反馈,并且超时(20 秒)会提示原因(素材过重 / 被安全软件拦截)
     并建议在控制栏勾选「硬件加速解码」后重试

4. 另外两处原本"点了没反应"的情况也补上了提示
   · 还没打开视频就点播放 → 会提示"请先打开一个视频文件"
   · 播放头已经停在选区末尾 → 会提示"没有可播放的内容,请把播放头往左拖"

5. 进度条现在有优先级:正在导出时点播放,不会打断导出的进度显示

■ 取消「双击时间轴 → 精确设置」

6. 双击时间轴不再弹出精确设置窗口(现在等同于两次单击,即单纯的跳转定位)
   · 需要精确输入起止时间:请点顶栏「精确设置」按钮
   · 预览区双击(还原 100% 缩放)、片段列表双击(跳回片段)保持不变

【安装位置】
本次已自动部署到: C:\RJ\LosslessVideoEditor\
桌面快捷方式: 无损视频剪辑

无损视频剪辑工具 v13.2 更新公告 (2026-09-27)
==============================================

【本次更新】全程进度反馈 + 硬件加速开关

■ 导入 / 导出 / 预览,全程有反馈

1. 导入进度条
   · 打开视频时的解析阶段会显示进度条(此前只有一行文字,大文件或慢盘上像"没反应")

2. 预览"◌ 解码中"指示
   · 抽帧超过约 0.25 秒时,预览区左上角浮出活动指示,拖动播放头时不再"无感"

3. 导出进度条增强
   · 左侧显示具体任务名与百分比(如"裁剪导出中… 42.5%")
   · 取消按钮统一为「✕ 取消」
   · 进度条改为自绘琥珀色,替代系统默认绿色,与深色主题统一、对比更清晰

■ 硬件加速解码(新增开关,默认关闭)

4. 控制栏勾选「硬件加速解码」即可开启,状态自动保存到 config.json,下次启动沿用
   · 开启后:预览抽帧 / 播放预览 / GIF 重编码走 GPU 解码(-hwaccel auto)
   · 适合 4K、高码率、HEVC / AV1 等重解码素材
   · 裁剪 / 合并是无损 stream copy,不参与解码,画质零损失、不受开关影响
   · 为何默认关闭:实测小文件(720p)上 GPU 初始化开销反而更大(663ms vs 254ms),
     只有重解码素材才划算,故做成按需开启

桌面快捷方式: 无损视频剪辑

【使用提示】

解压到程序目录, 有进度窗口, 完成后永久可用, 不需要联网。

无损视频剪辑工具 v12 更新公告 (2026-08-17)
==============================================

【一键下载】
本目录内: LosslessVideoEditor_v12.exe (约 172 MB, 内置 ffmpeg, 双击即用)

【v12 新功能】

■ 片段列表多选
1. Shift+点击范围多选, Ctrl+点击逐个多选
   · 选中多个片段后可一键批量删除
   · 块移动: 多选后点上移/下移, 整组保持相对顺序一起移动
   · 右键菜单自动显示"删除选中 (N)", 操作更直观

■ 导出参数记忆
2. GIF/MP3 质量档位自动记忆
   · 上次选择的 GIF/MP3 质量档位会保存到配置文件
   · 下次导出时默认选中上次的档位, 不用每次重新选

【v12 重要修复】

■ 速度下拉框卡死修复 (关键)
3. v11 点击速度下拉框会导致整个软件卡死、无法关闭
   · 根因: v11 使用 Toplevel + grab_set + wait_window, 在 Windows 上 grab 死锁
   · v12 改用原生 Menu.tk_popup(), 无 grab、无阻塞, 彻底消除卡死

■ 导入导出防卡死
4. 所有导出函数增加 busy 守卫
   · 导出进行中再次点击导出按钮直接忽略, 防止并发 ffmpeg 导致卡死
5. 所有对话框增加 lift() + focus_force()
   · 确保弹窗在最前面, 防止被主窗口遮挡导致"看不到弹窗、以为卡死"
6. 质量选择弹窗 5 分钟超时自动关闭
   · 防止异常情况下 grab 永久占用导致界面锁死

【保持不变】
- GIF/MP3 参数可调 / 速度 6 档位 / 深色风格下拉 / 片段拖拽排序
- 崩溃自动重启 / 播放头预览联动 / 片段右键菜单 / 导出后清理缓存
- 无损裁剪 / 合并 / 批量导出 / 精确到帧 / 空格预览
- 预览滚轮缩放(25%~400%)、双击还原、放大后拖拽平移
