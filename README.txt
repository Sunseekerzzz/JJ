无损视频剪辑工具 v13.4 (ondir 版)
===============================
解压后进入 LosslessVideoEditor 文件夹,双击里面的 LosslessVideoEditor.exe 即可启动,
无需任何额外安装。文件夹需整体移动,不能只拷 exe(它依赖同目录的 _internal/)。

界面风格:OBS Studio 深色主题(深蓝工具栏 + 黑色预览区 + 右侧控制面板)。

内置 ffmpeg
-----------
首次启动会自动从 exe 内部解压 ffmpeg/ffprobe/ffplay(约 440MB, 20~30 秒),
解压完成后永久可用,无需联网、无需手动下载。

如果首次启动被安全软件拦截,请把本程序加入白名单,或手动下载 ffmpeg 放入
同目录的 ffmpeg\bin\ 文件夹中。

核心功能
--------
1. 打开视频 → 自动抽帧预览(也支持把视频拖到 exe 图标上直接打开)
2. 拖动时间轴选择保留区间(起点橙色 / 终点青色 / 播放头红色;拖动播放头时预览实时联动)
3. 精确设置起止时间:点顶栏「精确设置」按钮(支持 时:分:秒.毫秒 或 秒数;已取消双击时间轴触发)
4. 裁剪导出:ffmpeg stream copy,像素级无损,秒级完成
5. 合并导出:把多个片段拼成一段,自动检查编码参数一致性
6. 播放预览:用 ffplay 试看**框选的区间**(从选区起点播到选区终点,不受播放头位置影响;
   可选 0.25x / 0.5x / 0.75x / 1x / 1.5x / 2x 速度)
   · 点击后底部会显示「正在启动播放器…」进度,播放窗口出现即自动收起(大素材首帧解码较慢时不再像"没反应")
7. 批量导出:把片段列表每个片段导出为独立文件(一键批量出片)
8. 片段列表右键菜单:定位 / 重命名 / 上移 / 下移 / 删除 / 清空
9. 片段列表拖拽排序:鼠标按住条目拖动调整顺序,与右键菜单联动
10. 导出 GIF 动图(可选 低/中/高 三档质量)与纯音频 MP3(可选 低/中/高 三档质量)
11. 预览缩放 + 平移:预览区滚轮缩放(25%~400%),放大后按住左键拖动平移查看细节
12. 崩溃自动重启:异常退出后自动重新拉起(1 分钟 4 次防死循环;正常关闭不重启)
13. 全程进度反馈:导入解析进度条 / 预览"解码中"指示 / 导出进度条(带任务名与百分比,可取消),操作不再"无感"
14. 硬件加速解码开关(默认关闭,状态存 config.json):4K / 高码率素材可开 GPU 解码,预览与播放更顺)

使用提示
--------
• 默认快速切割会对齐到关键帧(起点误差 ≤ 2 秒);勾选"精确到帧"可精确到帧,
  速度稍慢但同样不重编码、画质无损。
• 合并多个不同来源的视频前会检查分辨率/编码器/码率是否一致,不一致会提醒。
• 中文路径、emoji、带空格/特殊字符的文件名均正常导入。
